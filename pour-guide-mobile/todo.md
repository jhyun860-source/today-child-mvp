# Pour Guide 개선 작업

- [x] 레시피 헤더에서 큰 사진 영역을 제거하고 요약 정보와 작은 가니시 썸네일로 교체한다.
- [x] 재료·계량과 모든 제조 단계를 한 페이지에서 연속으로 볼 수 있는 전체 제조 모드를 구현한다.
- [x] 각 단계의 타이머를 인라인으로 배치하고 완료 체크가 전체 흐름을 방해하지 않도록 조정한다.
- [x] 휴대폰 화면에서 스크롤·글자 크기·하단 내비게이션 간섭을 확인한다.
- [x] 독립 이관본에도 동일한 화면 개선을 반영한다.
- [x] 컴팩트한 레시피 헤더에 완성 사진과 가니시 참고 사진을 추가한다.
- [x] 사진을 눌러 크게 볼 수 있게 하되 전체 제조 순서의 세로 흐름은 유지한다.
- [x] 휴대폰 화면과 독립 이관본에서 사진 참고 영역을 검증한다.
- [x] 메뉴, 재료, 제조 단계, 사진을 저장할 관리 데이터 구조를 정의한다.
- [x] 레시피 목록과 신규 메뉴 추가를 제공하는 관리자 화면을 만든다.
- [x] 메뉴명·카테고리·재료·제조 단계·완성/가니시 사진을 편집하는 폼을 만든다.
- [x] 저장된 변경 내용을 바텐더용 레시피 화면에 즉시 반영한다.
- [x] 관리 기능과 사진 입력을 독립 이관본에 문서화한다.
- [x] 완성 사진과 가니시 사진을 분리 저장하는 데이터 필드를 추가한다.
- [x] 관리자 폼에 완성 사진과 가니시 사진 업로드·교체를 각각 구현한다.
- [x] 바텐더 화면과 참고 모달에서 두 사진의 용도를 구분해 표시하고 저장 반영을 검증한다.
- [x] 완성 사진과 가니시 사진을 저장한 뒤 두 URL이 레시피 조회 응답에 함께 포함되는 통합 검증을 추가한다.
- [x] 관리자 저장 이후 바텐더 화면에서 두 참고 사진을 구분해 표시하는 경로를 검증한다.
- [x] tRPC 레시피 조회 응답이 완성 사진과 가니시 사진 URL을 함께 반환하는지 테스트한다.
- [x] 관리자 tRPC 사진 업로드가 역할별 경로와 저장 필드를 사용하고 바텐더 매핑으로 이어지는지 테스트한다.
- [x] 관리자 화면에서 기존 칵테일을 쉽게 찾을 수 있는 검색·선택 목록을 추가한다.
- [x] 선택한 기존 칵테일의 재료·순서·사진이 편집 폼에 명확히 로드되도록 안내와 상태를 보완한다.
- [x] 샘플 칵테일을 관리 화면에서 수정 가능한 초기 메뉴로 제공하는 방식을 결정하고 검증한다.
