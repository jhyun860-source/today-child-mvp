# Pour Guide

모바일에서 빠르게 칵테일 레시피를 찾고, 큰 계량값과 단계별 제조 흐름을 확인할 수 있는 **독립형 React/Vite 목업**입니다. 이 프로젝트는 특정 서비스에 종속되지 않는 표준 웹 프로젝트이므로, GitHub에서 복제한 뒤 어느 개발 환경에서나 이어서 개발할 수 있습니다.

## 포함된 목업 기능

| 기능 | 설명 |
| --- | --- |
| 레시피 탐색 | 이름, 베이스, 맛, 제조 방식 검색 및 카테고리 필터 |
| 제조 모드 | 단계별 제조 카드, 이전/다음 단계, 완료 상태 |
| 배치 전환 | 1x, 2x, 3x에 따라 모든 계량값 자동 변경 |
| 타이머 | 셰이크/스터 단계의 카운트다운 및 진동 알림 지원 |
| 즐겨찾기 | 레시피 저장 및 저장 목록 확인 |
| 모바일 UX | 엄지 손가락용 하단 탐색, 작은 화면 우선 구성 |

## 로컬 실행

Node.js 20 이상과 pnpm을 권장합니다.

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd cocktail-recipe-mobile
pnpm install
pnpm dev
```

브라우저에 표시되는 주소를 열면 됩니다. 배포용 파일은 다음 명령으로 생성합니다.

```bash
pnpm build
```

생성된 정적 결과물은 `dist/public`에 포함되므로 **GitHub Pages, Netlify, Vercel, Cloudflare Pages** 같은 정적 호스팅 환경에 배포할 수 있습니다.

## 다음 개발 단계

현재 레시피는 `client/src/pages/Home.tsx`의 샘플 데이터입니다. 실제 제품 단계에서는 이를 JSON/API/데이터베이스로 교체하고, 계정·권한·매장별 메뉴·관리자 편집·오프라인 캐시를 추가하면 됩니다. 이 목업은 백엔드를 포함하지 않으므로 실제 직원 계정이나 레시피 변경 기능은 아직 저장되지 않습니다.

생성 이미지와 앱 아이콘은 `client/public/assets`에 함께 포함되어 있습니다. 따라서 이 폴더만 그대로 복제해도 외부 서비스 전용 경로에 의존하지 않습니다.

## 라이선스와 이관

코드와 문서는 저장소에서 모두 확인·수정할 수 있습니다. 저장소를 다른 GitHub 계정이나 개발 환경으로 옮기려면 GitHub의 Import 기능 또는 일반 Git remote 변경을 사용하면 됩니다.
